# 排障指南

先看日志：`%LOCALAPPDATA%\BetterPinyin\logs\app.log`。里面会记录每次云联想的处理结果，例如：

```
19:37:52  [云联想] yisitalu → 伊斯塔露（来源 bing-osjson，锚点 候选窗）
19:38:10  [云联想] ystl：云端无可用候选（原始 12 条均被过滤）
19:38:25  [云联想] weiruan：5 条候选均已在本地区命中或读音不符
```

日志里没有输入内容本身以外的信息，可以放心贴到 issue 里。

## 症状 → 原因 → 处理

### 完全没反应，浮窗从不出现

1. 确认程序在托盘里运行。
2. 打开「设置 → 网络与环境」，看环境自检：
   - **微软拼音：未检测到** → 本功能只支持微软拼音。
   - **双拼：已开启** → 双拼下按键串不是全拼，功能会保持停用（这是设计如此）。
3. 看「设置 → 云联想 → 运行诊断」是否有记录：
   - 有记录但都是"云端无可用候选" → 网络或端点问题，去网络页做一次端点体检。
   - 完全没有记录 → 键盘钩子没收到按键。检查是否被安全软件拦截，或目标程序以管理员身份运行。

### 浮窗出现了，但按采纳键没上屏

- 目标程序是**管理员权限**运行时，普通权限程序无法向它发送输入（系统限制）。需要以管理员身份运行本程序。
- 日志里若出现 `上屏中止：组字未被取消`，说明 Esc 没能取消组字，此时程序会主动放弃上屏以避免"拼音与中文混杂"。

### 浮窗位置偏移

- 候选窗矩形来自 UI Automation，插入符来自系统 API，两者都是物理像素。若在**混合 DPI 的多显示器**环境下偏移，属于已知限制（目前按主显示器 DPI 换算）。
- 没有系统插入符的程序（Chromium、Electron 自绘文本）会退回鼠标位置定位，浮窗可能不在光标正下方。

### 云候选总是不出现

按顺序排查：

1. **是不是本来就有？** 云词与微软拼音当前候选重复时会主动隐藏（避免"云联想没带来新信息"）。日志会写"均已在本地区命中或读音不符"。
2. **是不是读音对不上？** 例如输入 `yisital` 时，云端给出「艾石头al87」这类混排词会被过滤。这是预期行为。
3. **是不是纯缩写？** `ystl` 这类直查返回的多是拉丁垃圾，会被整体过滤。全拼（`yisitalu`）与未打完的全拼（`yisital`）命中率明显更高。
4. **网络是否可用？** 网络页点「重新检测」，看是否有任一端点可用。

### 端点体检全部失败

- 检查是否需要代理。程序默认跟随系统代理，可在设置里改为自定义。
- 部分企业网络会拦截搜索建议接口，此时功能进入静默待机，不影响输入法本身。

### 程序启动后没有任何窗口

- 默认只在托盘中常驻，双击托盘图标打开设置。首次运行（尚无配置文件）会自动打开设置窗口。
- 若托盘图标也不见了，看日志里是否有 `OnStartup` 错误记录；程序会把启动异常写进日志并弹窗提示。

### 打字变卡

本程序的键盘钩子回调只做过滤与转交，不做任何 I/O。若确实感到卡顿：

1. 关闭云联想开关，确认是否由本程序引起。
2. 检查是否有其它程序也在装低级键盘钩子（多个钩子会串行执行）。
3. 把日志与复现步骤一并提交。

## 提交问题时请附上

1. `%LOCALAPPDATA%\BetterPinyin\logs\app.log` 的相关片段。
2. 「设置 → 网络与环境」页的自检结果截图。
3. Windows 版本（`winver` 里的版本号）。
4. 出问题的程序名称（记事本 / VS Code / Chrome / 微信 / 某个游戏…）。
